# Matrix Transpose

## Purpose
Converts rows into columns of Matrix A (menu option 8: `Transpose Matrix A`).

## Existing Function
`Matrix Matrix::transpose() const` (in `01_Matrix_Creation_Input/Matrix.cpp`)

## Validation
Works for any matrix size. The result has `columns of A` rows and `rows of A` columns.

## Example
```
A = 2 1 1         Transpose of A = 2 1 1
    1 3 2                          1 3 0
    1 0 0                          1 2 0
```
